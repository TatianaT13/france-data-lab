À propos de France Data Lab

Notre approche

Chaque observatoire part d'un jeu de données officiel et ouvert, l'agrège de façon transparente et le présente avec des cartes, des courbes et des classements. Les méthodes de calcul, les sources et les limites sont expliquées sur chaque page, pour que les chiffres puissent être compris, vérifiés et critiqués.

Mises à jour automatiques

Des tâches planifiées sur GitHub récupèrent les nouvelles données, recalculent les indicateurs et redéploient le site sans intervention manuelle.

Questions fréquentes

Qu'est-ce que France Data Lab ?
Un ensemble d'observatoires interactifs bâtis sur des données ouvertes françaises. Chaque page transforme un jeu de données publié par une administration en cartes, courbes et classements lisibles.
D'où viennent les données ?
De data.gouv.fr et des portails ouverts de l'INSEE, de la DGFiP, de RTE et du LCSQA. Chaque page indique sa source, sa méthode et ses limites.
Les données sont-elles à jour ?
Oui : les sites se régénèrent automatiquement (chaque jour ou chaque semaine selon la source). La date de dernière mise à jour est affichée sur chaque page.
Puis-je réutiliser les données ou le code ?
Le code est public sur GitHub. Les données agrégées sont téléchargeables au format JSON depuis le dossier data du site, dans le respect des licences des sources d'origine.
